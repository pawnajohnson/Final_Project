# Final_Project
This project explores a telecommunications dataset to understand customer retention, identify key factors driving churn, and find solution to keep at-risk subscribers. It covers data cleaning, exploratory data analysis (EDA), visualization.

# TELECOMMUNICATIONS DATASET(EDA- EXPLORATARY DATA ANALYSIS
## PROJECT OVERVIEW
This project uses Python to explore a telecom customer dataset and find out which customers are most likely to leave (churn). It covers 7,043 customers described by 21 attributes, including contract type, services used, billing details and tenure. The result is a clear picture of who churns and why, which the company can use to keep customers longer.
## BUSINESS PROBLEM
Telecom is a subscription business, so every customer who leaves takes recurring revenue with them. In this dataset 26.5% of customers (1,869 of 7,043) have churned. Winning a new customer usually costs more than keeping an existing one, so knowing which customers are at risk, and why, is worth more than broad discounts or acquisition spend.
## OBJECTIVES
• Measure the overall churn rate and how the customer base splits between churned and retained.
• Compare churned and retained customers on tenure, monthly charges and total charges.
• Find which contract, service, billing and demographic groups churn the most.
• Turn the findings into practical retention actions.
